# 검사 설계 공통 규칙 (2단계)

## 검사 목록과 서비스 내 이름
| # | 서비스 내 이름 | 문서 | 방식 | 문항 수 |
|---|---|---|---|---|
| 1 | 타고난 기질 탐색 | `temperament.md` | 자체 문항 + 결과 직접 입력 | 48 |
| 2 | 출생순위 탐색 | `adler.md` | 입력만 (문항 없음) | 0 (입력 2~4칸) |
| 3 | 융 유형 탐색 | `jung-type.md` | 자체 문항 + 4글자 유형 직접 입력 | 32 |

"TCI 검사", "MBTI 검사"라는 이름은 쓰지 않는다. 입력 화면에서만 "MBTI®, TCI 결과를 이미 알고 있다면"처럼 사실 지시로 언급한다. 제휴·승인을 암시하는 문구는 쓰지 않는다.

## 문항 작성 원칙
- 모든 문항은 이 저장소에서 새로 썼다. 기존 검사의 문항, 번역, 변형을 참고하지 않았다. 개념(차원 정의)만 이론에서 가져왔다.
- 응답 척도: 5점(전혀 아니다 1 ~ 매우 그렇다 5). 역방향 문항 점수는 `6 - 응답`.
- 차원마다 역방향을 40~50% 섞는다.
- 사회적 바람직성 완화: 좋고 나쁨이 뻔한 문장 대신 구체적 행동·상황으로 쓴다. 결과 문구에도 좋고 나쁨 서열을 두지 않는다.
- 문항은 차원 순서가 아니라 섞어서 제시한다(고정 시드 셔플, 같은 차원이 연속 3개 이상 나오지 않게).
- 한 화면 한 문항.

## 차원당 문항 수 근거
Spearman-Brown 공식으로 문항 평균 상관 r과 문항 수 k에서 척도 신뢰도를 어림한다. r은 **가정값(0.25~0.30)** 이며 실측이 아니다. 출시 전 파일럿 응답으로 Cronbach α를 실제로 계산해 문항을 조정해야 한다.

| k | r=0.25 | r=0.30 | 판단 |
|---|---|---|---|
| 3 | 0.50 | 0.56 | 개인 수준 해석에 부족 |
| 4 | 0.57 | 0.63 | 부족 |
| 6 | 0.67 | 0.72 | 최소선 |
| 8 | 0.73 | 0.77 | 권장 |

- 목표: 차원 점수 α ≥ 0.70 (자기이해용 참고 수준, 임상·선발용 아님).
- 기질 4차원은 6문항, 개념이 넓고 어려운 성격 3차원은 8문항, 융 유형 4축은 8문항.
- 3문항 척도는 쓰지 않는다. 프로이트 방어기제는 기제별(3문항)이 아니라 성숙도 수준별(6문항)로만 점수화한다.
- 한 검사 소요 시간 목표: 문항당 약 8초 기준 5~7분 이내.

## 채점 구조 (코드와 데이터 분리)
- 문항 데이터: `src/data/items/<test>.ts` (id, 텍스트, 차원, 방향)
- 채점 함수: `src/lib/scoring/<test>.ts` — 순수 함수. 입력 `{itemId: 1~5}`, 출력 차원 점수.
- 차원 점수 = (문항 점수 평균 - 1) / 4 × 100 → 0~100. 역방향 처리 후 평균.
- 응답 누락이 있으면 채점하지 않는다.
- 구간 표시는 규준 데이터가 없으므로 "척도 중간 기준"으로만 한다: 0~39 낮음 / 40~60 중간 / 61~100 높음. 인구 대비 순위처럼 보이는 표현("상위 n%")은 쓰지 않는다.
- 테스트: 역방향 처리, 경계값(전부 1, 전부 5, 전부 3), 누락 처리를 vitest로 검증.

## 결과 화면 공통
- 면책 문구(고정): "이 결과는 자기이해를 위한 참고용이며 임상 진단이나 전문 심리평가를 대체하지 않습니다."
- 근거 문헌과 한계 섹션을 검사별로 표시한다.
- 결과 저장은 동의한 경우에만. 동의 전에는 브라우저 메모리(세션)에만 둔다.

## 종합 단계(3단계)로 넘길 출력 형태
| 검사 | 출력 | 이산화 |
|---|---|---|
| 타고난 기질 | 7차원 점수 | 차원당 낮음/중간/높음 → 3^7 = 2,187 |
| 출생순위 | 첫째/중간/막내/외동 | 4 |
| 융 유형 | 4축 선호 방향 | 2^4 = 16 (균형 구간은 가까운 쪽으로 배정하되 "약한 선호" 표시) |
| 마음의 구조 | 3구조 점수 + 방어 수준 3점수 | 6개 척도 × 3단계 → 3^6 = 729 |
| 내면의 그림자 | 3척도 점수 + 원형 친화 상위 1 | 3^3 × 4 = 108 |

조합 계산과 유형군 묶기는 `docs/character.md`에서 한다.
